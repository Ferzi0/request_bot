# STATUS — Telegram-бот приёма заявок (Ferz)

Единый источник правды. Формат записи: этап, статус, что сделано, что проверено (команда → результат), проблемы, долг.
Связанный проект: `../ferz-site` (сайт-визитка; кнопка «Заявка через Telegram-бота» ведёт сюда; факты о заказчике — в `../ferz-site/STATUS.md`).

## Команда агентов и цикл этапа

Оркестратор (Sonnet 5.5) · исполнитель и антибаг (Opus) · монитор (Haiku, пишет «Сводку») · хранитель git (Haiku, коммит после каждого этапа).
Цикл: исполнитель → антибаг → монитор → приёмка оркестратора → коммит. Ничего не объявляется готовым без запущенной проверки.

## Решения заказчика (2026-10-17)

- Заказчик хорошо знает Python и aiogram, хочет глубже изучить; код должен быть образцовым и читаемым (архитектура, комментарии по делу), чтобы по нему можно было учиться.
- Стек: Python + aiogram 3. Работает на Mac заказчика (long polling), хостинг позже, после полной готовности экосистемы (сайт + бот + письма на почту).
- Заявка: человек проходит диалог → бот отправляет **заявку заказчику в личный чат с ботом** (ADMIN_ID) сообщением с данными, указанными клиентом. Клиенту: «Принято, отвечу в течение суток».
- Диалог собирает то же, что форма на сайте: как обращаться; почта или Telegram для ответа; тип проекта (Сайт-визитка, Лендинг, Telegram-бот, Веб-сервис, Интернет-магазин, Другое); задача в двух-трёх фразах (до 1000 символов); согласие на обработку данных (ссылка на политику сайта).
- Хранение: пока ТОЛЬКО пересылка заказчику, без БД. БД (SQLite → дальше) подключаем позже, архитектуру делаем так, чтобы хранилище добавлялось без переписывания.
- Тон: формально, по-человечески, на «вы», только русский.
- Название кнопки/действия: «Оставить заявку». Имя и username бота — решит заказчик (создаёт в @BotFather).
- Токен бота и ID заказчика — ТОЛЬКО в `.env` (в git не попадает), заказчик вставляет сам, в чат токен не присылать.
- Коммиты — только от имени заказчика (его git-конфиг), без строк атрибуции (Co-Authored-By и подобных).
- Окружение: Python 3.14.8 на Mac (aiogram совместимость проверить; при проблемах — Python 3.12/3.13 в venv без системных изменений).
